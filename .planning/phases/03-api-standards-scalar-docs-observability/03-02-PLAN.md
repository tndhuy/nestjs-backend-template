  - Trace exporter: if `process.env.OTEL_EXPORTER_OTLP_ENDPOINT` is set, use `OTLPTraceExporter`; else use `ConsoleSpanExporter` as dev fallback

  - Export the `sdk` instance (caller calls `sdk.start()`)
  - Wrap in try/catch — log error to console.error if SDK init fails, still export null

11. `app.useGlobalInterceptors(new TransformInterceptor(reflector), new TimeoutInterceptor());`
12. Swagger/Scalar setup:

    ```typescript
      .addBearerAuth()
      .build();
    ```

```typescript
LoggerModule.forRoot({
  pinoHttp: {
    level: process.env.NODE_ENV !== 'production' ? 'debug' : 'info',
    genReqId: (req) => req.headers['x-correlation-id'] as string,
    transport: process.env.NODE_ENV !== 'production'
      ? {
          target: 'pino-pretty',
          options: {
            colorize: true,
            translateTime: 'SYS:yyyy-mm-dd HH:MM:ss',
            ignore: 'pid,hostname',
          },
        }
      : undefined,
    serializers: {
      req: (req: any) => ({ method: req.method, url: req.url }),

    },
  },
}),
```
