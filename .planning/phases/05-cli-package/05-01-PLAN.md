**File 1 — `packages/create-app/src/replacements.ts`:**

Per D-03, define the placeholder mapping:

```typescript
export function toPascalCase(kebab: string): string {
  return kebab.split('-').map(s => s.charAt(0).toUpperCase() + s.slice(1)).join('');
}

export function buildReplacements(serviceName: string): [string, string][] {
  return [
    ['nestjs-backend-template', serviceName],
    ['NestjsBackendTemplate', toPascalCase(serviceName)],
  ];
}
```

Also export a `validateServiceName` function that accepts only `[a-z0-9][a-z0-9-]*[a-z0-9]` (min 2 chars) — rejects path traversal (`..`, `/`, `\`), uppercase, spaces, leading/trailing hyphens. Returns `undefined` on success or error string on failure. Per T-05-01 threat model.

**File 2 — `packages/create-app/src/scaffold.ts`:**

Per D-02, implement copy + search/replace (no template engines):

Export an async `scaffold(options: ScaffoldOptions)` function:

```typescript
export interface ScaffoldOptions {
  serviceName: string;
  db: 'postgres' | 'mongo';
  modules: string[]; // 'redis' | 'otel' | 'kafka'
  destDir: string;
}
```

Implementation steps:
1. Resolve the template dir: `path.join(__dirname, '..', 'templates', options.db)` — per D-04/D-06, picks postgres or mongo snapshot.
2. Copy template to destDir using `fs.cp(templateDir, destDir, { recursive: true })`.
3. Walk all files in destDir recursively. For each file:
   - Replace file **contents**: `content.replaceAll(from, to)` for each replacement pair.
   - Skip binary files: check if file is binary by reading first 512 bytes and checking for null bytes. If binary, skip content replacement.
4. Walk all files/dirs again for **name** replacement: rename any file or directory whose name contains a placeholder string. Process deepest paths first (sort by depth descending) to avoid renaming a parent before its children.
5. Per D-08, `src/example/` (which is in both template snapshots) is always kept — no removal logic.
6. Module toggle removal is handled by a separate function (Plan 02 wires this). For now, export a `removeModule(destDir: string, module: string)` stub that does nothing — Plan 02 implements it.
7. After all replacements, call a `patchPackageJson(destDir, options)` function that:
   - Reads the generated package.json
   - Sets `"name"` to the service name
   - If `db === 'mongo'`: removes `@prisma/client` and `prisma` deps, adds `mongoose` and `@nestjs/mongoose`
   - Writes back the patched package.json

**File 3 — `packages/create-app/src/cli.ts`:**

Per D-01, use `@clack/prompts` exclusively. Per D-05, all prompts are interactive (no CLI flags).

Start with shebang: `#!/usr/bin/env node`

```typescript
import { intro, outro, text, select, multiselect, spinner, isCancel, cancel, confirm } from '@clack/prompts';
import { scaffold } from './scaffold';
import { validateServiceName } from './replacements';
import { join } from 'path';
```

Flow:
1. `intro('create-app -- NestJS DDD scaffolder');`
2. `text()` for service name — use `validateServiceName` as validator. Placeholder: `'my-service'`.
3. Check `isCancel()` — if cancelled, call `cancel('Cancelled.')` and `process.exit(0)`. Use a `guardCancel` helper for all prompts.
4. Per D-04, `select()` for database — options: `{ value: 'postgres', label: 'PostgreSQL', hint: 'default' }` and `{ value: 'mongo', label: 'MongoDB' }`.
5. Per D-07, `multiselect()` for optional modules — options: Redis, OpenTelemetry, Kafka. Set `required: false` (user can select none).
6. `confirm()` — show summary of choices, ask to proceed.
7. `spinner()` — start with 'Scaffolding project...'
8. Call `scaffold({ serviceName, db, modules, destDir: join(process.cwd(), serviceName) })`.
9. Stop spinner with 'Project scaffolded!'
10. `outro()` with next steps: `cd ${serviceName} && npm install && npm run start:dev`

Wrap `main()` in try/catch — on error, log with `cancel()` and `process.exit(1)`.
